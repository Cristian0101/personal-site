# Bundled site fonts

Newsreader, Inter, Fraunces, and IBM Plex Sans are distributed under the SIL Open Font License 1.1. Original licenses are included. Geist continues to be supplied by its existing package.

These unmodified WOFF2 files preserve the families, styles, weight declarations, language subsets, and fallback metrics already used through next/font/google. They are served locally so hosted builds do not depend on Google Fonts URL parsing or network availability. The manifest records SHA-256 checksums; filenames retain their previous build identifiers. Font binaries are not modified internally.

Upstream sources and licenses:
- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
